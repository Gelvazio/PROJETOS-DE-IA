# Site a partir do Maps

Gera uma landing page de uma página a partir do link de uma empresa no Google Maps.

**Ferramentas:** Claude, Google Maps e Vercel

**Clientes:** Mecânicas, clínicas, pet shops, lojas de bairro, pizzarias

## O que faz

- Extrai nome, categoria, endereço, horários, nota e avaliações
- Monta HTML responsivo sem frameworks externos
- Cabeçalho, hero, serviços, avaliações, como chegar e rodapé com horários
