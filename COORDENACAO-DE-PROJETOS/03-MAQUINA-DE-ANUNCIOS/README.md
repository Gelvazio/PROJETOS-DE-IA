# Máquina de Anúncios

Analisa um anúncio que performa bem na Meta e cria variações no mesmo ângulo.

**Ferramentas:** Claude, Biblioteca de Anúncios da Meta e Higgsfield

**Clientes:** E-commerces, agências de marketing, freelancers de tráfego

## O que faz

- Identifica ângulo, problema emocional, promessa central e reação do público
- Gera 3 variações com headline, abertura e CTA diferentes
- Cada variação vem com uma justificativa
