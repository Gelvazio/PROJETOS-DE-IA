# Dashboard 01 — Vendas

**Para:** lojas, distribuidoras, times comerciais. Mostra meta do mês, ticket médio e ranking de vendedores.

## Prompt

```
Analise os dados de vendas que vou enviar e crie um dashboard
interativo em HTML com:

- KPIs no topo: faturamento do mês, meta, ticket médio e total de pedidos
- Gráfico de barras: vendas por dia vs. meta diária
- Gráfico de rosca: vendas por canal (loja, WhatsApp, site, marketplace)
- Tabela de ranking de vendedores com % da meta e status visual
  (verde = acima de 90%, amarelo = 70–90%, vermelho = abaixo de 70%)

Use fundo escuro (#1a1a2e), destaque em verde (#00c896),
alertas em vermelho (#ff4d4d). Layout responsivo.
```

## Dados necessários

Antes de enviar, peça ao cliente uma planilha com: **data, valor, canal, vendedor e status do pedido**. Se não tiver tudo, o Claude ajusta com o que tem.
