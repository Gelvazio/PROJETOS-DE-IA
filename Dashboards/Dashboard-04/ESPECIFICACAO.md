# Dashboard 04 — Executivo

**Para:** donos de empresa que querem ver tudo em 1 minuto. Faturamento, lucro e margem do ano.

## Prompt

```
Com os dados que vou enviar, crie um painel executivo em HTML:

- KPIs principais: faturamento no ano, lucro líquido, margem líquida,
  clientes ativos (com variação % vs. ano anterior)
- Gráfico de área: faturamento x lucro mês a mês
- Tabela: top 7 clientes por valor comprado no ano
- Gráfico de barras: margem líquida por mês

Design minimalista, fundo escuro (#0d0d1a), números grandes,
azul claro (#6699ff) para destaques. Sem excesso de informação.
```

## Dica

Esse é o dashboard mais fácil de vender porque o dono olha e entende na hora. Se o cliente não tiver os dados organizados, ofereça a organização como serviço separado.
