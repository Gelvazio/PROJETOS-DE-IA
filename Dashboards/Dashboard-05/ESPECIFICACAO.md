# Dashboard 05 — Metas

**Para:** empresas com vários setores ou lojas. Mostra cada área vs. sua meta e a projeção de fechamento do ano.

## Prompt

```
Crie um dashboard de metas em HTML com os dados que vou enviar:

- KPIs por área: % atingido da meta, com barra de progresso colorida
  (verde = acima de 80%, amarelo = 60–80%, vermelho = abaixo de 60%)
- Gráfico de barras agrupadas: realizado x meta por mês
- Projeção de fechamento: com base na tendência atual, quanto a empresa
  vai fechar no ano vs. a meta anual
- Tabela detalhada: cada área com meta, realizado, % e status

Fundo escuro, verde limão (#aaff00) para realizado,
cinza (#555) para meta, destaque em roxo para a projeção.
```

## Dica

Funciona melhor quando cada área tem uma meta clara em número. Se o cliente ainda não tem metas definidas, ofereça ajuda para estruturar isso — vira um serviço extra.
